Pickd — Mobile concepts · v1

Four mobile directions.

Each phone shows the Dashboard view at iPhone Pro size (360 × 760 with notch + status bar). Tracker / MultiPick views would inherit the same chrome. The shared bottom nav sits across all four — switch between Dashboard, Tracker, MultiPick, Settings.

01
Editorial stack
Direct port of the desktop editorial style. Pickd. wordmark, big headline, single-column stat strip with rich sublines. Each stat tappable. Quick-action cards under the strip for "Add bet" / "New multi". Most faithful to desktop.
